## firekylin 主题修改


修改 firekylin 里面的主题，修改成功后，运行 `node stc.config.js`, 对源码进行压缩编译。

或者直接克隆本文件夹 到项目根目录执行 build.sh 脚本进行优化

文件产生在 themes 文件夹下。此文件直接上传覆盖就好。
